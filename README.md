# Network Traffic Analysis and Monitoring Using Wireshark

## Project Overview
This project focuses on capturing and analysing network traffic using Wireshark in a Kali Linux environment. It explores three important network protocols: DNS, TCP and UDP.

## Objectives
- Understand DNS queries and responses.
- Analyse TCP communication and the three-way handshake.
- Examine UDP packets and their transport characteristics.
- Gain practical experience with network packet analysis.

## Tools Used
- Kali Linux
- Wireshark
- Firefox
- Oracle VirtualBox

## Practical Implementation

### 1. DNS Analysis
Applied the `dns` display filter to inspect DNS queries and responses and understand how domain names are resolved into IP addresses.

### 2. TCP Analysis
Applied the `tcp` display filter to inspect TCP packets and study connection establishment through SYN, SYN-ACK and ACK flags.

### 3. UDP Analysis
Applied the `udp` display filter to inspect UDP packets, source and destination ports, and QUIC traffic carried over UDP.

## Learning Outcomes
- Learned to capture and analyse network packets using Wireshark.
- Understood DNS query and response mechanisms.
- Studied TCP connection establishment.
- Understood UDP-based communication.

## Conclusion
This project provided practical exposure to network traffic monitoring and analysis using Wireshark and helped develop an understanding of DNS, TCP and UDP protocols.
